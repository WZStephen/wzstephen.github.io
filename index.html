LLM Serving Control Plane / Inference Scheduling

赵伟驰 / Weichi Zhao

专注 Kubernetes 原生的大模型推理平台：把模型服务生命周期、Router / Worker 收敛、批量推理与流量治理连接成可上线、可观测、可恢复的生产链路。

专业方向

Serving Control Plane

模型服务生命周期与就绪收敛

用 Kubernetes CRD / Controller 管理模型工作负载、Service / Endpoint、Router Worker 注册、健康状态、发布与回滚。

Batch Inference

高吞吐、可恢复的离线推理

围绕 OpenAI Batch API、任务分片、多副本协调、租户并发和失败恢复，长期支撑生产数据蒸馏与批量生成任务。

Routing & Reliability

网关、Router 与生产可观测性

连接 LiteLLM / Higress、SGLang / vLLM 与 Kubernetes，关注流量治理、推理指标、缓存效率和全链路故障定位。
