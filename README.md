# wzstephen.github.io

Personal GitHub Pages site for AI infrastructure daily notes, technical blog
archives, and bilingual resume pages.

## Files

- `index.html`: blog homepage.
- `blog/index.html`: all-post archive.
- `_posts/`: AI technical sharing posts generated by OpenClaw cron.
- `resume/index.html`: English online resume.
- `resume/index-cn.html`: Chinese online resume.
- `Files/EN_Resume_Weichi_Zhao.pdf`: generated English PDF resume.
- `Files/CN_Resume_Weichi_Zhao.pdf`: generated Chinese PDF resume.

## Daily AI Technical Reports

New daily reports should be written directly into `_posts/` using Jekyll post
filenames:

```text
YYYY-MM-DD-ai-technical-report.md
```

Each post needs front matter:

```yaml
---
layout: post
title: 'AI 技术分享 — YYYY 年 M 月 D 日'
date: YYYY-MM-DD 09:00:00 +0800
categories: [ai-technical-report]
---
```

## Generate PDFs

From this directory:

```bash
google-chrome --headless --disable-gpu --no-sandbox --no-pdf-header-footer --print-to-pdf=Files/EN_Resume_Weichi_Zhao.pdf resume/index.html
google-chrome --headless --disable-gpu --no-sandbox --no-pdf-header-footer --print-to-pdf=Files/CN_Resume_Weichi_Zhao.pdf resume/index-cn.html
```
