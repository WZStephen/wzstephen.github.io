多租户离线批量推理平台

OpenAI Batch API · Scheduling · Recovery
  • 面向数据蒸馏、数据生成和评测等大规模长任务，对外兼容 OpenAI Batch API；用户提交 JSONL 后，平台自动完成流式解析、任务分片、并发调度和结果汇总。
  • 通过持久化任务进度、Kubernetes Lease 选主和分片重新认领，使调度器或执行实例异常后能够从已有进度继续执行，避免整批任务重跑。
  • 采用至少一次后端执行与结果级去重，结合 custom_id 跳过已落盘请求，实现请求级错误隔离和长期稳定运行。
